# Приёмка шаблона v2

## Границы

Этот кандидат реализован по команде «Давай работай!» после предложения пересборки.
Проверки ниже не разрешают merge, deploy, запуск рабочего бота, реальные массовые
сообщения или перенос старой базы. `AGENTS.md` создан после отдельного подтверждения.
Подробные договорённости: [V2-SCOPE.md](V2-SCOPE.md).

## Воспроизводимая автоматическая проверка

- Команды и зависимости: корневой README и `.github/workflows/tests.yml`.
- `tests/test_app.py`: настоящий Dispatcher, переходы, тексты, редактирование,
  предпросмотр, роль, устаревшая панель, повтор запуска, расписание и страницы.
- `tests/test_storage.py`: реальная SQLite, версии черновиков, снимки получателей,
  гонки запуска/получения работы, смена статусов, отписка, восстановление.
- `tests/test_content.py`: UTF-16/entities, длинные посты, фото/видео/альбомы,
  кнопки, ограничения API и отказ до запуска некорректного контента.
- `tests/test_delivery.py`: известные и неопределённые ошибки, частичный прогресс,
  отмена, ошибка записи подтверждения, ограниченный повтор только безопасного отказа.
- `tests/test_integrated_delivery.py`: настоящий Store вместе с отправщиком,
  повторы паузы, отписка после снимка, перезапуск посреди запроса, 429.
- `tests/test_runtime.py`: настоящий HTTP-транспорт aiogram на loopback-двойнике,
  запуск polling, остановка, перезапуск, webhook с верным/неверным секретом,
  блокировка второго процесса на том же файле базы.
- `tests/test_regressions.py`: идемпотентная отписка, поздний альбом при переходе
  в другой черновик, закрытые права БД, отказ от модификации старой схемы,
  маскирование токена, безопасный legacy-экспорт на синтетических данных.
- `tests/test_config.py`: безопасные адреса API, часовой пояс, webhook,
  скрытие секретов в repr, явное включение/выключение рассылок.

Двойники используются только в тестах. Ни один тест не получает настоящий токен,
не обращается к реальному Telegram и не читает исторические CSV.
Успешный автоматический прогон не является приёмкой внешнего Bot API или владельцем.

## Живой прогон — ещё не выполнен

Нужен отдельный тестовый бот и только собственные тестовые аккаунты. Реальные
адресаты и рабочий токен не переиспользуются без отдельного разрешения.

- Меню → помощь → назад; заметка → изменить → назад; перезапуск → заметка на месте.
- Выйти в меню во время редактирования и снова открыть сохранённый черновик.
- Прислать жирный/курсивный текст, ссылку, фото, видео, смешанный альбом и длинный пост.
- Проверить внешний вид предпросмотра и доставку «себе» в настоящем Telegram.
- Изменить текст, убрать медиа и заменить ссылочные кнопки; отменить ввод без потери черновика.
- Подтвердить маленькую рассылку только тестовым подписчикам; нажать запуск дважды.
- Назначить время с минутами и проверить в своей зоне, не ждать начала следующего часа.
- Пауза → продолжение; остановка с подтверждением; отписавшийся не получает следующий пост.
- Удалить старую панель и открыть `/menu`; на старые кнопки получить понятный ответ.
- Перезапуск во время рассылки: неопределённый запрос не отправляется автоматически повторно.
- Сравнить отчёт с фактическими сообщениями тестовых аккаунтов. Доставлено ≠ прочитано.

Не вызывать специально реальный flood/rate-limit и не платить за ускорение рассылки.
Результат живого прогона, точный SHA и решение владельца фиксируются отдельно.
